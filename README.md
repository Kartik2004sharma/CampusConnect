# CampusConnect

An AI-Powered Smart Campus Management & Student Service Portal.

## Structure
- `server/`: Node.js + Express backend
- `client/`: React.js frontend (Vite)

## Setup
1. Clone the repository
2. Navigate to `server/` and run `npm install`, set up `.env` based on `.env.example`.
3. Navigate to `client/` and run `npm install`.
4. Run `npm run dev` in both directories to start the development servers.
